Deploy to GitHub Pages:

1. Create a GitHub repository named `USERNAME.github.io` (replace `USERNAME` with your GitHub username).
2. On your machine:

```bash
git init
git add .
git commit -m "Initial portfolio"
git branch -M main
git remote add origin https://github.com/USERNAME/USERNAME.github.io.git
git push -u origin main
```

3. Wait a few minutes — your site will be available at `https://USERNAME.github.io`.

If you prefer using a repository with a different name, enable GitHub Pages from the repo settings and publish from the `main` branch.
